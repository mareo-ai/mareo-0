# Ink & Paper（Mareo 运营页主题）

自定义主题，用于 `/stats/` 三个页面。借用 [theme-factory](../../vendor/theme-factory/) 中
**Modern Minimalist** 的灰阶纪律（单一强调色、清晰边界、无阴影、无渐变），但按数据看板的需要重做：

## 设计意图

一个每天要读两分钟的内部页面，应该像**印刷品**而不是仪表盘模板：

- 底色是纸（暖白），不是冷灰；深色模式是暖黑，不是纯黑
- 正文用墨色；三级文字（正文 / 次级 / 最弱）在两种模式下都过 WCAG 4.5:1
- 只有**一个**强调色（深青），用于数据关系，不用于装饰
- 单位、比例、边框一律 1px 发丝线；**不用阴影、不用渐变、不用玻璃**
- 数字用衬线体（`Iowan Old Style` / `Palatino` / `Songti`），等宽对齐用于表格

## Token

| 角色 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| bg | `#f6f4ef` | `#14130f` | 页面底（纸感） |
| panel | `#ffffff` | `#1b1a16` | 卡片/表格 |
| border | `#e3ded4` | `#2c2a24` | 发丝线 |
| text | `#171614` | `#f2efe8` | 正文与数字 |
| muted | `#5f5a52` | `#b3ada2` | 次级（标题、表头） |
| faint | `#6f6a60` | `#9a948a` | 最弱（注释、脚注） |
| accent | `#1d5f5a` | `#7fc7bd` | 数据强调（深青） |
| warn | `#8a4b00` | `#e0a95e` | 告警（琥珀） |
| good | `#1c6b43` | `#74c79a` | 正常（松绿） |

> 所有文字色对 bg 与 panel 的对比度都 ≥ 4.5:1（由测试与审计脚本核对）。

## 版式

- **报头（masthead）**：小字栏目标签 + 衬线大标题 + 右侧窗口/生成时间，底部一条 1px 实线
- **导语**：本周结论用 19px 衬线排一行，不用彩色横幅
- **数字条**：KPI 横向排列，块与块之间用发丝线分隔（不用卡片），数字 40px 衬线
- **小节标题**：11px、字距 0.12em、大写感的小标签 + 右侧延伸的发丝线
- **表格**：表头下 1px 深线，行间浅线，数字右对齐且等宽
