# Dashboard（Mareo 运营页主题）

`/stats/` 三个页面使用的主题。取向是**主流 SaaS 数据看板**，不是印刷品或作品集页面。

## 参照

- **Vercel 设计 token**：[设计系统参考](https://github.com/beefiker/superloopy/blob/main/skills/superloopy-frontend/references/design/vercel.md)
  —— 边缘用 `box-shadow: 0 0 0 1px` 而不是 `border`、正文 `#4d4d4d`、单一链接蓝强调、4/8/12/16/32 间距刻度、大字号负字距。
- **看板骨架**（Stripe / Vercel / Linear / Grafana 的共同点）：**吸顶顶栏**（产品名 + 标签页 + 时间范围/生成时间）→ 页面标题区 → 指标卡 → 分区表格/列表。

| warn | `#b4530a` | `#f5b544` |
| good | `#067647` | `#3ecf8e` |

所有文字色对 bg 与 panel 的对比度 ≥ 4.5:1（脚本实测）。

## 布局规则

1. **导航必须在首屏**：吸顶顶栏，三个页面平铺，当前页 `aria-current="page"` 高亮
2. 页面标题 + 一句说明（这个页面回答什么问题）
3. 结论条：一个圆点 + 一句话，异常时圆点变琥珀并链到 Health
4. 指标卡：白底 + 1px 阴影边 + 8px 圆角，数字 28px/600 负字距
5. 分区标题 13px/600；分隔靠留白，不靠横线
6. 表格：卡片式整体，表头 12px 弱化，数字右对齐且等宽，文本左对齐

## 曾经走过、已放弃的方向

第一版做成了「报纸/印刷品」：衬线标题、纸感底色、发丝线 KPI 条、无卡片。
**负责人否掉了**，理由很具体：`三个页面首屏都没有导航`，以及整体不像一个能用的运营后台。
这份文件记录下这一点，避免以后重复走同一条路。
