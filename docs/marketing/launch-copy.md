## 二、技术社区（V2EX / 即刻 / 掘金）

> **做了一个桌面 AI agent，想找人试试**
>
> Mareo 是 DeepSeek Harness 的桌面外壳。Harness 本身是个 agent 运行时（能调工具、跑命令、读文件），但装它要 Node、要命令行、要自己配 API key——大部分人卡在这一步。Mareo 把这些包了起来：下载、登录、直接用。
>
> 具体能干的：Git 仓库里改 bug 并跑测试；把一堆 CSV 清洗合并；把资料整理成 PPT；批量重命名整理文件。不是"回答一个问题"，是"把一件事做完"。
>
> 模型是选配的：日常用便宜那两档，复杂任务切到更强的两档。
>
> 免费额度每天重置，够轻度使用；也能充值，¥10 起。
>
> https://mareo.cn 有问题可以直接回帖或者私信。

## 写文案的三条约束

1. **不说「永久免费」**。额度是可调参数，说永久就变成假话。
2. **不点名厂商模型**（OpenAI / GPT）——产品里用 `Mareo-O-*` 的命名，对外也一致。
3. **写具体场景，不写形容词**。「能改 bug 并跑测试」比「强大的编程能力」有说服力。

## 已知的坑

- 邮件里写过「半年」，实际 `v0.1.4` 距当时只有 40 天。**时间与日期一律先查 tag 或数据库再写。**
- 邮件里写过「最近 30 天用了 10000 多次」，实际取的是全历史。**写数字前确认 SQL 的口径和文案描述一致。**
